# Plantillas Fase 4 - SDD

Plantillas reutilizables para convertir backlog en features construibles bajo Spec-Driven Development.

## Plantillas disponibles
- [spec-funcional.md](spec-funcional.md)
- [spec-tecnica.md](spec-tecnica.md)
- [spec-tareas.md](spec-tareas.md)

## Regla de uso
- Usa estas plantillas para iniciar una feature en `specs/<nnn-feature>/`.
- Mantiene separacion clara entre funcional, tecnico y tareas.
