# Frontend Integration Hub

Workspace `Nx` que contiene la consola administrativa Angular del proyecto.

## Estructura

- `apps/web`: aplicacion principal de administracion y operacion
- `apps/web-e2e`: pruebas end-to-end
- `libs/core`: servicios y fundamentos compartidos
- `libs/features`: features de negocio
- `libs/shared`: componentes y utilidades transversales

## Comandos principales

```sh
npm start
npm run build
npm run test
npm run e2e
```

## Stack

- `Angular 21`
- `Nx`
- `Angular Material`
- `Angular CDK`
- `Angular Aria`
- `TailwindCSS v4`
- `Signals`
