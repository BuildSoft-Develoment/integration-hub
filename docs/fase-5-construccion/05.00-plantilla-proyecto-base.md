# Plantilla de proyecto base

## Objetivo

Documentar la estructura real del repositorio sin forzar una estructura generica que rompa la ejecucion actual.

## Estructura real

- `platform-app/`: backend Quarkus y pruebas Java
- `frontend/`: workspace Nx/Angular con app `web`, librerias y `web-e2e`
- `docs/`: documentacion por fases
- `specs/`: features bajo SDD
- `qa/`: baseline de calidad y evidencia
- `ops/`: deploy y operacion aplicada
- `ci/`: baseline de pipeline
- `releases/`: snapshots documentales
- `likec4/`: fuente de arquitectura como codigo
- `ejemplos/`: ejemplos reutilizables de configuracion
- `keycloak/`: realm base
- `otel/`: collector config

## Equivalencia con el template

- `src/` del template equivale funcionalmente a:
  - `platform-app/src/`
  - `frontend/apps/`
  - `frontend/libs/`
- `tests/` del template equivale funcionalmente a:
  - `platform-app/src/test/`
  - `frontend/apps/web-e2e/`
  - pruebas frontend del workspace `Nx`

La referencia oficial de esta equivalencia vive en `docs/transversal/90.06-equivalencias-estructura-real.md`.

## Backend

- parent Maven en `pom.xml`
- modulo principal `platform-app`
- dependencias base para REST, OIDC, scheduler, health, telemetry y Quinoa

## Frontend

- app principal `web`
- pruebas `web-e2e`
- librerias en `libs/core`, `libs/features`, `libs/shared`

## Pruebas y scripts

- `test-jdk25.cmd`
- `test-quarkus-jdk25.cmd`
- scripts de arranque y secretos en la raiz
