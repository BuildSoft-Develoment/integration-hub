## Objetivo

Documentar la estructura real sobre la que hoy se construye y evoluciona el producto.

## Estructura real

- `platform-app/`: backend Quarkus y pruebas Java
- `frontend/`: workspace Nx/Angular con app `web`, librerias y `web-e2e`
- `docs/`: documentacion por fases
- `specs/`: features bajo SDD
- `qa/`: calidad y evidencia
- `ops/`: deploy y operacion aplicada
- `ci/`: pipeline y verificacion documental
- `releases/`: snapshots documentales
- `likec4/`: fuente de arquitectura como codigo
- `ejemplos/`: referencias operativas de configuracion
- `keycloak/`: realm base
- `otel/`: collector config

## Entradas de construccion

- `specs/` ordena las capacidades antes de cambios grandes.
- `src/README.md` y `tests/README.md` funcionan como puertas de entrada documentales para codigo y pruebas.
- `qa/`, `ops/`, `ci/` y `releases/` concentran evidencia, salida a ambientes y trazabilidad operativa.

La referencia oficial de esta estructura vive en `docs/transversal/90.06-estructura-repositorio-real.md`.

## Backend

- parent Maven en `pom.xml`
- modulo principal `platform-app`
- dependencias base para REST, OIDC, scheduler, health, telemetry y Quinoa

## Frontend

- app principal `web`
- pruebas `web-e2e`
- librerias en `libs/core`, `libs/features`, `libs/shared`
