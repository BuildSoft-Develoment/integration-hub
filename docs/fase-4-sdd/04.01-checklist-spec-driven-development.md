## Checklist

- [x] Existe cartera inicial de `specs/`.
- [x] Las features principales del producto tienen `spec-funcional`, `spec-tecnica` y `spec-tareas`.
- [x] La numeracion funcional ya se refleja en `qa/` y `ops/`.
- [ ] Cada nueva feature debe nacer en `specs/` antes de cambios grandes.
- [ ] Todo cambio arquitectonico relevante debe revisar `ADR`.
- [ ] Las specs deben mantenerse sincronizadas con codigo, QA y operacion.
