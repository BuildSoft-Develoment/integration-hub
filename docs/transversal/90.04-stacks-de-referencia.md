## Objetivo

Presentar stacks de referencia como fichas comparables para acelerar la seleccion tecnica.

## Stacks disponibles

- `Quarkus + Angular/Nx`
- `Spring Boot + React`
- `Node + Next.js`
- `Java Monolith`

## Regla de uso

- No elegir stack solo por preferencia del equipo.
- Cruzar escenario, RNF, operacion esperada y ecosistema interno.
- Revisar la ficha completa en `../../stacks/README.md`.

## Stack base del proyecto

La base real del repositorio hoy es:

- backend: `Quarkus`
- frontend: `Angular + Nx`
- identidad y acceso: `Keycloak`
- persistencia principal: `PostgreSQL`
- observabilidad: `OpenTelemetry`

3. Registrar la seleccion final en fase 3 y en el `ADR` correspondiente cuando cambie.
