# Modos de trabajo

## Objetivo

Explicar como trabajar en el repositorio segun el nivel de incertidumbre.

## Modo exploratorio

Usar cuando:

- el problema todavia es ambiguo
- hay varias opciones tecnicas o funcionales
- se requiere comparativa o spike

Salidas minimas:

- supuestos
- opciones evaluadas
- recomendacion
- siguiente aterrizaje a `docs/`, `ADR` o `specs/`

## Modo estructurado

Usar cuando:

- ya existe arquitectura base
- hay backlog o expectativa de entrega
- la capacidad va a construccion, QA, deploy u operacion

Salidas minimas:

- documentos oficiales en `docs/`
- `ADR` si cambia arquitectura o tecnologia
- `specs/` si una feature entra a ejecucion
- evidencia en `qa/`, `ops/`, `ci/` o `releases/`

## Regla para este proyecto

El repositorio ya debe operar principalmente en `modo estructurado`.
