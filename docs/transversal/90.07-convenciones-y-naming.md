# Convenciones y naming

## Documentacion

- usar nombres por fase `00.xx` a `08.xx`
- usar `90.xx` para documentos transversales
- mantener nombres descriptivos y estables

## Specs

- usar numeracion incremental `NNN-nombre-feature`
- mantener siempre `spec-funcional.md`, `spec-tecnica.md` y `spec-tareas.md`

## Operacion

- separar baseline documental de artefactos operativos reales
- no mover scripts, secretos o configuraciones productivas sin validar compatibilidad
