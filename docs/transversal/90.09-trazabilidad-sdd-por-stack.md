## Objetivo

Conectar la seleccion de stack con la forma concreta en que se materializan features bajo `Spec-Driven Development (SDD)`.

## Referencias actuales

Las features del proyecto deben sostener trazabilidad entre requerimiento, arquitectura, codigo, pruebas y evidencia operativa. Referencias actuales:

- `../../specs/000-ejemplo-feature/`
- `../../specs/001-bandeja-trabajo-expedientes/`
- `../../specs/002-cambio-estado-expediente/`
- `../../specs/003-historial-auditoria-expediente/`

## Regla de uso

- Cada feature nueva debe partir de una carpeta propia en `specs/`.
- Cada feature debe mantener `spec-funcional.md`, `spec-tecnica.md` y `spec-tareas.md`.
- Mantener trazabilidad hacia codigo real en `platform-app/`, `frontend/`, `src/` y `tests/` segun corresponda.
