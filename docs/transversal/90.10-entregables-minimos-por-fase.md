## Objetivo

Resumir que artefactos minimos debe dejar cada fase en este proyecto para considerarse util y trazable.

## Fase 0

- vision
- roadmap
- estimacion
- roles
- preparacion del proyecto

## Fase 1

- analisis de requerimientos
- modulos, casos de uso e historias cuando el dominio lo exige

## Fase 2

- resumen UX/UI
- journeys
- pantallas
- wireframes o criterio visual
- validacion UX

## Fase 3

- arquitectura
- decisiones de tecnologia
- despliegue
- `ADR`
- `LikeC4` o equivalente vigente

## Fase 4

- regla `SDD`
- features en `specs/`
- trazabilidad a QA y Ops

## Fase 5

- estructura real de construccion
- mapa de backend y frontend
- verificacion tecnica base

## Fase 6

- plan de pruebas
- casos
- evidencias
- control de defectos

## Fase 7

- checklist de salida
- pipeline o baseline equivalente
- runbook
- rollback
- release o snapshot

## Fase 8

- operacion continua
- monitoreo
- metricas
- backlog evolutivo
