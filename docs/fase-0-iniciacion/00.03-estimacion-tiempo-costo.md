# Estimacion tiempo y costo

## Objetivo

Dejar una referencia inicial de esfuerzo para ejecutar el roadmap. Esta estimacion es orientativa y debe refinarse por feature en `specs/`.

## Supuestos

- equipo pequeno con capacidad backend, frontend y operacion
- reutilizacion de la base ya implementada
- prioridad en estabilizar antes que ampliar alcance

## Estimacion inicial por tramo

| Tramo | Esfuerzo estimado | Observacion |
| --- | --- | --- |
| Fundacion documental y cierre tecnico | 2 a 4 semanas | ordenar arquitectura, docs y deuda de base |
| MVP operativo | 4 a 8 semanas | cerrar flujos manuales y pantallas principales |
| Operacion controlada | 3 a 6 semanas | scheduler, QA y deploy por ambiente |
| Hardening productivo | 4 a 8 semanas | HA, seguridad, backup, tuning |

## Factores de variacion

- complejidad de integraciones externas
- volumen real de datos por proceso
- disponibilidad de infraestructura `PRE/PRO`
- cambios de alcance sobre UX o modelo de procesos
