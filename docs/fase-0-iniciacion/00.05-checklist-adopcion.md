# Checklist de adopcion

## Checklist

- [x] Existe `README.md` principal con contexto del producto.
- [x] Existe indice documental por fases en `docs/`.
- [x] La arquitectura tiene documentos en `fase-3` y fuente `LikeC4`.
- [x] Existe baseline de `specs/` para nuevas capacidades.
- [x] Existe baseline de `qa/`, `ops/`, `ci/` y `releases/`.
- [x] Los activos operativos reales siguen en rutas compatibles.
- [x] El frontend deja de depender solo del README boilerplate de Nx.
- [ ] Cada nueva feature priorizada debe entrar por SDD antes de construccion relevante.
