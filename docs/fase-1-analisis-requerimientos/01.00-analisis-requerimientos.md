## Requerimientos funcionales principales

- `RF-01` Configurar fuentes `filesystem`, `ftp`, `sftp` y `rest`.
- `RF-02` Configurar readers `txt`, `csv`, `xls`, `xlsx`, `json` y `xml`.
- `RF-03` Diseñar procesos con tareas configurables y ordenadas.
- `RF-04` Ejecutar procesos manuales y programados.
- `RF-05` Consultar ejecuciones, auditoria, archivos procesados y resumen operativo.
- `RF-06` Reprocesar corridas con error o archivos pendientes manteniendo linaje.
- `RF-07` Administrar acceso por roles sobre UI y API.
- `RF-08` Administrar conexiones a motores de datos (`ORACLE`, `POSTGRESQL`, `SQLSERVER`, `MYSQL`, `MONGODB`), probar conectividad e introspeccionar su metadata (esquemas/tablas/columnas/rutinas) para las tareas DB.
- `RF-09` Programar procesos (scheduling) y consultar las programaciones vigentes.
- `RF-10` Configurar el tema del sistema (apariencia, idioma y modo de barra lateral) de la consola.

## Requerimientos no funcionales relevantes

- `RNF-01` Trazabilidad por proceso, tarea y archivo.
- `RNF-02` Seguridad con `OIDC` y `Keycloak`.
- `RNF-03` Observabilidad con `OpenTelemetry`.
- `RNF-04` Soporte para alto volumen mediante procesamiento por lotes y streaming.
- `RNF-05` Operacion monitoreable y recuperable por ambiente.

## Casos de uso principales

### UC-01 Configurar fuente

- definir fuente `filesystem`, `ftp`, `sftp` o `rest`
- registrar parametros de conexion y ruta
- dejar la fuente disponible para procesos

### UC-02 Configurar reader

- definir formato `txt`, `csv`, `xls`, `xlsx`, `json` o `xml`
- guardar layout y opciones por tipo

### UC-03 Disenar proceso

- crear definicion de proceso
- agregar tareas ordenadas
- configurar `FILE_READ`, `DB_WRITE`, `DB_EXECUTE_SP`, `DB_EXECUTE_FN`, `REST_CALL` y/o `NOTIFICATION`
- para tareas DB (`DB_WRITE`/`DB_EXECUTE_SP`/`DB_EXECUTE_FN`), seleccionar una conexion activa y su tabla/rutina destino

### UC-09 Configurar conexion

- definir conexion a `ORACLE`, `POSTGRESQL`, `SQLSERVER`, `MYSQL` o `MONGODB`
- registrar parametros (driver/url/credenciales) con secretos `${secret:...}`
- probar conectividad e introspeccionar metadata (esquemas/tablas/columnas/rutinas)

### UC-04 Ejecutar proceso manualmente

- seleccionar proceso activo
- correr bajo demanda
- revisar estados, auditoria y archivos procesados

### UC-05 Ejecutar proceso programado

- detectar procesos activos y programados
- disparar ejecucion
- registrar inicio, tareas y resultado

### UC-06 Consultar ejecuciones y auditoria

- filtrar por proceso, estado o fecha
- revisar errores, tiempos y trazas
- correlacionar auditoria, ejecuciones y archivos

### UC-07 Reprocesar luego de error

- identificar corrida fallida
- corregir causa externa o configuracion
- reejecutar con evidencia de linaje

### UC-08 Administrar acceso

- administrar roles, realm y clientes en `Keycloak`
- restringir acceso por perfil y recurso

## Reglas funcionales clave

- `FILE_READ` requiere `sourceDefinition` y `readerDefinition`
- las tareas `DB_WRITE`, `DB_EXECUTE_SP` y `DB_EXECUTE_FN` requieren una `connectionDefinition` activa
- `MONGODB` no expone rutinas: la introspeccion de procedimientos/funciones solo aplica a motores relacionales
- solo procesos activos y marcados como programados son disparados por el scheduler
- solo perfiles administrativos crean o editan catalogos (fuentes, readers, conexiones, procesos)
- `operator` ejecuta procesos
- `auditor` consulta ejecuciones y eventos
- auditoria y trazas deben correlacionarse por `processExecutionId`

## Escenarios criticos

- fuente remota no disponible
- timeout de API externa
- configuracion invalida del reader
- token OIDC invalido
- error de persistencia o alto volumen
- scheduler disparando procesos inactivos

## Integraciones relevantes

- `Keycloak` para identidad y autorizacion.
- `PostgreSQL` para catalogos, ejecuciones, staging y auditoria.
- sistemas externos consumidos por fuentes `REST`, `FTP` y `SFTP`.
- servicios externos invocados por tareas `REST_CALL`.
