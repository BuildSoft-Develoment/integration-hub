# Plan de despliegue

## Objetivo

Definir la estrategia de despliegue on-prem para `DEV`, `PRE` y `PRO`.

## Principios

- mismo stack logico por ambiente
- promocion controlada de binarios y configuracion
- seguridad y observabilidad desde la base

## DEV

- entorno de desarrollo e integracion local
- soporte con `docker-compose.yml`
- datos sinteticos o anonimizados

## PRE

- validacion previa a produccion
- certificados, DNS y secretos cercanos al setup productivo
- smoke tests funcionales antes de promover

## PRO

- aplicacion en `Kubernetes` con al menos dos nodos
- balanceo, secretos externos, observabilidad y backup corporativo
- endurecimiento de red, certificados y operaciones

## Configuracion externa por ambiente

- datasource
- OIDC y clientes Keycloak
- endpoints REST
- credenciales de fuentes
- scheduler
- exportadores de trazas
