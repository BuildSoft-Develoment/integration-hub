# Decisiones de tecnologia

## Decisiones base

- `Quarkus` como backend principal por tiempo de arranque, perfil cloud/on-prem y compatibilidad nativa.
- `Angular 21` con `Nx` para la consola administrativa.
- `Quinoa` para empaquetar la UI dentro del artefacto Quarkus.
- `Keycloak` externo para autenticacion y autorizacion OIDC.
- `PostgreSQL` como persistencia interna del producto.
- `OpenTelemetry` para trazabilidad distribuida.

## Criterios adicionales

- `Hibernate ORM` se mantiene para la base interna de plataforma.
- `JDBC` y pools programaticos se usan para conexiones externas dinamicas.
- `Testcontainers` se usa para validar compatibilidad de integraciones relacionales en pruebas.
- El modelo de extension favorece registries y providers en lugar de carga dinamica de plugins en runtime.
