## Objetivo

Resumir la arquitectura vigente del proyecto y su relacion con la operacion.

## Componentes principales

- `frontend/` como consola administrativa Nx/Angular
- `platform-app/` como aplicacion Quarkus
- `PostgreSQL` para catalogos, ejecuciones, auditoria y staging
- `Keycloak` como IAM externo
- `OpenTelemetry Collector` y backend de trazas

## Modelo operativo

La plataforma separa tres responsabilidades internas:

- `Source Providers` para adquisicion de contenido
- `Reader Providers` para interpretacion del contenido
- `Task Providers` para ejecutar acciones sobre los datos

## Atributos de calidad relevantes

- disponibilidad diferenciada por ambiente
- procesamiento batch y escritura por lotes
- seguridad basada en roles
- observabilidad por proceso, tarea y archivo
- mantenibilidad por providers y documentos `ADR`

## Riesgos principales

- complejidad del motor configurable
- compatibilidad native de librerias
- dependencia de integraciones externas
- alto volumen de datos
- drift entre documentacion y codigo
