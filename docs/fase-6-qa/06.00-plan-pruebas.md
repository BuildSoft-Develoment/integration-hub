# Plan de pruebas

## Objetivo

Definir el baseline de QA sobre la solucion actual.

## Niveles de prueba

- pruebas unitarias y de integracion para `platform-app`
- pruebas de frontend y `e2e` en `frontend/`
- smoke tests operativos por ambiente

## Flujos criticos a cubrir

- configuracion de fuentes
- configuracion de readers
- diseno y ejecucion de procesos
- consultas de ejecuciones, auditoria y overview
- autenticacion y autorizacion con Keycloak

## Comandos base actuales

- `test-jdk25.cmd`
- `test-quarkus-jdk25.cmd`
- `npm run test` dentro de `frontend/`
- `npm run e2e` dentro de `frontend/`
