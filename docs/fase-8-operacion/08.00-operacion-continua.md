# Operacion continua

## Objetivo

Consolidar la operacion base del producto a partir del runbook y del sizing actual.

## Operacion diaria

- validar disponibilidad UI y API
- validar login OIDC
- revisar scheduler
- revisar ejecuciones fallidas
- revisar trazas y auditoria

## Recuperacion

- reinicio controlado de aplicacion
- restauracion de base de datos
- restauracion de secretos y configuracion

## Metricas minimas

- procesos ejecutados por estado
- ultima ejecucion programada
- tiempo por tarea
- filas procesadas
- fallos por proceso
- latencia DB y REST
