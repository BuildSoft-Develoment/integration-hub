# Referencias de IA

[README principal](../../README.md) | [Indice docs](../../docs/README.md) | [Volver a ai](../README.md)

Esta carpeta agrupa checklists y criterios cortos que un `agent`, `prompt` o `skill` puede cargar segun el tipo de trabajo.

## Para que sirve
- evitar prompts demasiado largos o repetitivos,
- reutilizar el mismo criterio de verificacion entre fases,
- separar conocimiento de apoyo de los artefactos oficiales del proyecto.

## Regla de uso
- Una referencia no reemplaza un entregable oficial.
- Una referencia no sustituye `docs/`, `specs/`, `ops/` ni `qa/`.
- Carga solo la referencia minima necesaria para el trabajo actual.
