# Gate 7-8

## Objetivo
Validar readiness de salida y operacion continua posterior.

## Evidencia minima
- pipeline operativo,
- branch o worktree cerrable,
- resumen PR/merge o release,
- rollback,
- runbook,
- monitoreo,
- metricas,
- backlog evolutivo.

## Bloqueantes tipicos
- release sin smoke checks,
- branch con tareas abiertas o cambios no relacionados,
- rollback no probado o no documentado,
- falta monitoreo activo,
- operacion sin backlog de mejora.
