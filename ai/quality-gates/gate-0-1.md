# Gate 0-1

## Objetivo
Validar que el proyecto tiene direccion, alcance y base documental minima para seguir.

## Evidencia minima
- vision,
- requerimientos iniciales,
- matriz de huecos fase 1,
- roadmap,
- estimacion,
- roles.

## Bloqueantes tipicos
- no hay problema u objetivo claros,
- faltan RF/RNF visibles,
- no existe matriz de huecos o hay huecos abiertos sin responsable,
- reglas de negocio criticas no tienen RF/RNF asociado,
- el analisis sigue en texto instructivo.
