# Prompt - Generar spec tecnica

## Objetivo

Definir componentes, contratos, riesgos y estrategia tecnica de una feature.

## Entradas

- spec funcional
- arquitectura
- errores esperados
- restricciones de seguridad y operacion

## Salida esperada

- `specs/<nnn-feature>/spec-tecnica.md`
- `ADR` si cambia arquitectura
