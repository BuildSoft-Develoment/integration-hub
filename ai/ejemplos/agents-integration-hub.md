# Ejemplos de agents para Integration Hub

- `planner-agent`: priorizar una nueva capacidad de integracion y decidir si entra a `specs/`
- `architect-agent`: definir una nueva familia de providers o cambios de despliegue
- `backend-agent`: implementar tarea o reader nuevo en `platform-app/`
- `frontend-agent`: extender catalogos, designer u overview en `frontend/`
- `qa-agent`: preparar cobertura y evidencia por feature
- `devops-agent`: preparar salida a `PRE/PRO` y monitoreo asociado
