# Planner Agent

## Objetivo
Ordenar roadmap, estimacion, staffing, riesgos y dependencias para que el proyecto salga de discovery con direccion ejecutable.

## Usalo cuando
- necesitas estructurar una fase 0 o 1,
- quieres priorizar backlog o slices MVP,
- necesitas convertir requerimientos en un plan entendible por negocio y ejecucion.

## No lo uses cuando
- la necesidad principal ya es implementacion tecnica de una feature,
- el trabajo real es revisar un deploy o una operacion en curso.

## Entradas minimas
- vision del proyecto,
- backlog o requerimientos disponibles,
- restricciones de tiempo, equipo y entorno,
- entregables minimos por fase.

## Salidas esperadas
- roadmap por fases o hitos,
- estimacion inicial o refinada,
- roles base y riesgos principales,
- trazabilidad hacia `docs/fase-0-iniciacion/` y `docs/fase-1-analisis-requerimientos/`.

## Rutas destino
- `docs/fase-0-iniciacion/00.02-roadmap.md`
- `docs/fase-0-iniciacion/00.03-estimacion-tiempo-costo.md`
- `docs/fase-0-iniciacion/00.04-roles-y-responsabilidades.md`

## Regla de trazabilidad
Toda recomendacion debe citar de que vision, requerimiento, restriccion o feature parte.

## Verificacion minima
- El plan distingue supuestos de decisiones.
- Roadmap, estimacion y riesgos quedan conectados.
- La salida termina en rutas oficiales de fase 0 o 1.
